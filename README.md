# 🚀 Space Mission Analysis

## 📌 Project Overview
This project explores space mission data using Python to understand mission outcomes, launch trends, organisation performance, and mission costs.

## 🎯 Objectives
- Analyse mission success, failure, and pre-launch failure.
- Explore space missions across years and decades.
- Identify organisations conducting the most missions.
- Compare mission success rates across organisations.
- Explore mission costs and their relationship with mission outcomes.
- Visualise patterns using charts and statistical summaries.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed
- Data exploration and missing-value analysis
- Data type conversion and date feature extraction
- Mission status distribution
- Year-wise and decade-wise mission trends
- Organisation-wise performance analysis
- Mission cost distribution and outlier exploration
- Rocket status versus mission outcomes
- Data visualisation using bar charts, line charts, boxplots, and heatmaps

## 📁 Project Files
- `SpaceProject.py` — Python analysis code
- `space_mission_dataset.csv` — Dataset used for analysis

## ⚙️ How to Run

1. Download or clone this repository.
2. Install the required libraries:

   `pip install pandas numpy matplotlib seaborn`

3. Keep the CSV dataset in the same folder as the Python script.
4. Update the dataset path in the script to:

   `pd.read_csv("space_mission_dataset.csv")`

5. Run the Python script in your Python environment.
